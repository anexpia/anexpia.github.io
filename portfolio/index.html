About me​

Hello! I'm a proficient scripter with 5+ years of experience. I first began with building late 2019 and later learned scripting - around April 2020 - as it was a necessity for me to achieve what I wished to create with my builds at the time. Later on, I found my passion in scripting.

I excel at writing maintainable and efficient code, I'm quick at adapting to unfamiliar code, reading and organizing messy codebases, and learning new concepts whenever needed.
My main focus is designing and making backend systems as well as plugins, though I can do most of everything else.

Plugins / Libraries​

Plox

Custom coding language used in Project: SCP
Supports many features such as classes, custom embedder datatypes and APIs, sandboxed Instance access with full control over what you can use and privilege identities.

Small example of its capabilities.
P:SCP's community made many things that are honestly quite amazing.

CSG Library

Uses EditableMesh & a CSG algorithm written in luau. Can handle thousands of triangles in a single frame.
it uses a variant of Sutherland-Hodgman algorithm that only uses vectors to minimize memory allocations and be as performant as it is.

Server-authoritative projectiles

Blue dots: client hit position
Red dots: server hit position

Markua

A lightweight, tag-based markup text formatting system for Luau, inspired by XML/HTML.\

DevRoam

This is a plugin that lets you move around in studio with your own character. It emulates regular movement and camera behavior in edit mode as much as possible while providing extra handy features.

BufferEncoder

This is a module that serializes any form of table you provide to it into a buffer as efficiently as possible without relying on schemas unlike the majority of the other publicly available serializers. It supports all datatypes you'd realistically have in a table and can be easily modified for any of your needs.

Squish

This is a fork of Squash.
Its an optimized and extended fork with added features such as Deduplication, Support for new type solver, and overall more friendly API.

MoreEditors

A plugin that adds draggers for beams, lights, stellar bodies (sun & moon), and moving objects along 2 axes.

TextWrapper

This is a module that splits provided text into multiple lines efficiently. It supports rich text and can also provide offsets of characters to find within the text

Seamless Rig Updater

Updates rigs instantly without using relying on Humanoid:ReplaceBodyPartR15() or risking humanoid dying when replacing torso / head.
